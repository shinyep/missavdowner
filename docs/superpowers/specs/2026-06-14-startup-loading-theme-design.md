# 启动准备界面主题统一设计

## 背景

当前应用启动时会先显示 Electron 预加载阶段的准备界面。这个界面的全屏背景和窗口底色使用了深色值，与当前主界面的浅暖色主题不一致，导致启动时出现明显“黑屏感”。

## 目标

- 将启动准备界面的视觉基调统一到现有浅暖色主题
- 消除窗口创建早期和预加载遮罩阶段的黑色背景
- 不改动启动流程、交互逻辑和现有文案，只做最小必要的视觉统一

## 范围

### 包含

- [electron/main.ts](G:/videodown/electron/main.ts) 中 `BrowserWindow` 的 `backgroundColor`
- [electron/preload.ts](G:/videodown/electron/preload.ts) 中启动 loading 遮罩与旋转方块的颜色

### 不包含

- Vue 渲染层页面结构调整
- 新增启动文案、Logo、额外动画
- 改动业务逻辑或启动时序

## 方案

采用与现有主题一致的暖色系：

- 窗口底色使用 `#fff8f4`
- 启动遮罩背景使用浅暖色渐变，避免纯黑突兀感
- 启动动画主色使用主题橙色 `#ff9800`

## 验收标准

- 启动窗口在内容渲染前不再显示黑色背景
- 预加载准备界面不再出现深色全屏遮罩
- 修改后本地回归检查能够同时覆盖窗口背景色与 loading 样式
